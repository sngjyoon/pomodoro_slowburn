# Slowburn

A minimalist Pomodoro timer with a GitHub-style heatmap of your focused time over the last 52 weeks.

- Set focus and break lengths, with optional long breaks, auto-start, and counting early stops
- Every focus session feeds a year-long heatmap
- Runs entirely in the browser; data stays in `localStorage`

## Development

```bash
npm install
npm run dev
npm run test
npm run build
```

Deployed to GitHub Pages on every push to `main` (see `.github/workflows/deploy.yml`).
